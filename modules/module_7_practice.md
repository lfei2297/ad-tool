### 变体 C：比例切分配额版

**文件名：** `module_7_proportion.py`

**改动需求：**

后备补齐不用环形轮询，改成按比例切分：

```
账号1 需要补齐 6 条
后备品类有 SKU-A（2 变体）、SKU-B（3 变体）、SKU-C（1 变体）

按素材数比例分配：
  A 占比 2/6 = 33% → 应分 2 条
  B 占比 3/6 = 50% → 应分 3 条
  C 占比 1/6 = 17% → 应分 1 条
```

具体实现：
1. 计算后备品类中每个 SKU 的变体数量
2. 按变体数量分配剩余缺口（整数分配，余数给变体最多的）
3. 从每个 SKU 中按顺序取对应数量的变体（跳过全局已消耗）
4. 不跨账号接续指针，每个账号独立计算配额

**思考题（写完回答）：**
- 比例分配相比环形轮询，对账号 3/4 公平性有何影响？
- 为什么原版作者选择环形轮询而不是比例分配？
- 如果 SKU-A 有 100 个变体而 SKU-B 只有 1 个，比例分配的问题是什么？
